# ADR 0003: standard German first, Swiss dialect as comprehension

**Status:** accepted

The goal is B2 for office work in Zurich. Exams, documents and written work use standard German.
Everyday Swiss speech is Schweizerdeutsch, a dialect. The book teaches standard German (with the
Swiss standard variants flagged in boxes) and treats the dialect as listening comprehension from B1 on,
because Swiss speakers switch to standard German when addressing a learner.

Consequence: text uses `ß` as in Germany; Swiss `ss` is shown in the Switzerland boxes and Appendix D.
