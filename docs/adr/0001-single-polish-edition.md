# ADR 0001: one edition (Polish explanations, German content)

**Status:** accepted

The reader is a Polish speaker who knows English. The explanations (grammar, traps, strategy)
are Polish; the German is the content. Maintaining a second explanation language would double
the surface that no native speaker has reviewed yet, so it is deferred until the German itself
is reviewed. The house preamble's edition switch (`\def\houselang`) is the extension point if an
English edition is wanted later.
