\section{Passiv: \de{werden} $+$ Partizip II}
Strona czynna: \de{Das Team testet den Code.} Strona bierna: \de{Der Code \textbf{wird} (vom Team) \textbf{getestet}.} Dopełnienie
w bierniku staje się \emph{podmiotem}; wykonawca znika albo wraca jako \de{von} + celownik. Klamra jak zawsze:
odmieniony \de{werden} na 2.\ miejscu, imiesłów na końcu.

\begin{center}\small
\begin{tabular}{@{}lll@{}}
\toprule
\textsf{\textbf{Czas}} & \textsf{\textbf{Forma}} & \textsf{\textbf{Przykład}}\\
\midrule
Präsens & \de{wird / werden $+$ PII} & \de{Der Server wird neu gestartet.}\\
Präteritum & \de{wurde / wurden $+$ PII} & \de{Der Fehler wurde behoben.}\\
Perfekt & \de{ist / sind $+$ PII $+$ worden} & \de{Der Fehler ist behoben worden.}\\
Modalny & \de{muss $+$ PII $+$ werden} & \de{Der Test muss ausgeführt werden.}\\
\bottomrule
\end{tabular}
\end{center}
Wykonawca: \de{von} + osoba lub instytucja (\de{vom Team}, \de{von Anna}), \de{durch} + środek lub przyczyna (\de{durch einen Fehler},
\de{durch das Update}). Passiv bez podmiotu: \de{Hier wird gearbeitet.} \de{Es wird getanzt.}

\begin{zasada}[Kiedy Passiv?]
Gdy ważny jest \emph{proces lub wynik}, nie wykonawca, albo wykonawca jest nieznany lub oczywisty. Instrukcje, raporty
i dokumentacja używają Passiv: \de{Zuerst werden die Daten geladen. Dann wird der Test gestartet. Das Ergebnis wird gespeichert.}
\end{zasada}

\begin{falle}
\de{werden} w Passiv jest czymś innym niż \de{werden} w Futur (\de{Ich werde arbeiten}): to \emph{imiesłów} decyduje.
Błąd: \de{Der Code ist getestet} zamiast \de{wird getestet} (to stan, nie czynność; patrz jednostka~40). Drugi: \de{Das wurde von
ich gemacht}: po \de{von} celownik (\de{von mir}). Trzeci: Perfekt Passiv ma \de{worden}, nie \de{geworden}.
\end{falle}

\begin{szwajcaria}
W szwajcarskich dokumentach i umowach Passiv jest bardzo częsty (\de{Die Kündigung muss schriftlich erfolgen}). W mowie
dominuje strona czynna. W ogłoszeniach: \de{Gesucht wird ein Software-Engineer}, czyli „poszukiwany jest inżynier”.
\end{szwajcaria}

\begin{praca}
Opis wdrożenia: \de{Zuerst wird der Code geprüft. Danach werden die Tests ausgeführt. Wenn alle Tests bestanden sind,
wird das Release freigegeben und bereitgestellt.} Incydent: \de{Der Fehler wurde gestern gemeldet und heute behoben.}
Przekształć krok po kroku swój pipeline w taki tekst.
\end{praca}

\section{Dialogi}
\textbf{Dialog 1 --- status wdrożenia}
\begin{dialog}
\turn{A}{Wie ist der Stand? Wurde das Release schon freigegeben?}{Jaki jest stan? Czy wydanie zostało już zatwierdzone?}
\turn{B}{Noch nicht. Die Tests werden gerade ausgeführt. Danach wird der Code geprüft.}{Jeszcze nie. Testy są właśnie uruchamiane. Potem kod będzie sprawdzony.}
\turn{A}{Und wann wird bereitgestellt?}{A kiedy zostanie wdrożone?}
\turn{B}{Wenn alles erfolgreich war, heute Abend. Der Kunde wird informiert.}{Jeśli wszystko się powiedzie, dziś wieczorem. Klient zostanie poinformowany.}
\end{dialog}

\section{Ćwiczenia}
\begin{cwiczenia}
\exitem{Passiv Präsens: \de{Das Team testet den Code.}}{\de{Der Code wird (vom Team) getestet.}}
\exitem{Passiv Präsens: \de{Man startet den Server neu.}}{\de{Der Server wird neu gestartet.}}
\exitem{Passiv Präteritum: \de{Man behob den Fehler.}}{\de{Der Fehler wurde behoben.}}
\exitem{Passiv Perfekt: \de{Man hat den Fehler behoben.}}{\de{Der Fehler ist behoben worden.}}
\exitem{Passiv z modalnym: \de{Man muss den Test ausführen.}}{\de{Der Test muss ausgeführt werden.}}
\exitem{Uzupełnij: \de{Die Datei \dots{} gespeichert.} (Präsens)}{\de{wird}}
\exitem{Uzupełnij: \de{Die Dateien \dots{} gestern gelöscht.} (Präteritum)}{\de{wurden}}
\exitem{Wykonawca: \de{Der Fehler wurde \dots{} Anna behoben.}}{\de{von}}
\exitem{Przyczyna: \de{Der Ausfall wurde \dots{} ein Update verursacht.}}{\de{durch}}
\exitem{Popraw: \de{Der Fehler ist geworden behoben.}}{\de{Der Fehler ist behoben worden.}}
\exitem{Przetłumacz: „Najpierw dane są ładowane, potem zapisywane.”}{\de{Zuerst werden die Daten geladen, dann werden sie gespeichert.}}
\exitem{Przetłumacz: „Klient został poinformowany.”}{\de{Der Kunde wurde informiert.}}
\end{cwiczenia}
